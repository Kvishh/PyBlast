# PyBlast

PyBlast is a survival roguelike game where you defeat horde of enemies and try to survive for 10 minutes. Defeat enemies and level up to obtain upgrades that will help you last long in the cave. Equipped with dashing and slowing time, try to fight the enemies with the abilities you chose along the way.

## How to play

1. `git clone` this repository.

2. Ensure you are in the project directory and in your terminal/command line, type `python main.py`.
